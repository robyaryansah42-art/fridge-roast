My smart fridge texts me that the milk expired, then shows me an ad for milk, then judges the takeout I ordered instead — it's a snitch with a touchscreen. `main.ts` (Node 22, stdlib only) writes that single 155-character roast line as a constant to `entry.txt` inside the output directory (`MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`), so the program is fully deterministic: every run produces the exact same file.
